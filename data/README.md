# Data directory

- `synthetic/`: entirely invented examples for deterministic demo/testing; not real market reporting or investment advice.
- `sample/`: generated engine outputs. Recreate them with `python run_engine.py`.
- `public/`: reserved for datasets whose licences/terms explicitly permit the intended use and redistribution.

Do not add scraped/API data here until its source, licence, retention and redistribution terms are checked. Never store API keys in this directory.
